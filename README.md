# AwaasAI

AI-Assisted Housing Finance & Construction Platform

AwaasAI is a mobile-first platform that simplifies housing finance and
construction guidance using Retrieval-Augmented Generation (RAG).

## Planned Features

- Housing finance guidance
- Document requirement assistance
- RAG-based answers with source citations
- Construction guidance
- Field-officer copilot
- Customer application tracking
- Missing-document detection
- Low-bandwidth mode
- Cached information for limited-connectivity environments

## Tech Stack

- React Native
- Spring Boot
- Python / FastAPI
- PostgreSQL
- pgvector
- LLM + embeddings
- Docker
